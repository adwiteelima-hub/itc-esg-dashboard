# Complete ITC ESG Dashboard

Open `index.html` in a browser.

This is a standalone replacement dashboard built around the 12-indicator methodology:
E1-E4, S1-S4, G1-G4.

Features:
- Executive Overview
- Environmental / Social / Governance pages
- 12-indicator scorecard
- Methodology and formulas
- What-if analysis
- Data input and recalculation
- Validation checks

Current base result: 89.2/100, Strong.

Important: This is an academic model, not an official ITC ESG rating. Academic benchmarks are explicitly labelled.
